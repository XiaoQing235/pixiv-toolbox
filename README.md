# Pixiv Toolbox

在 Pixiv 浏览作品时，直接预览大图、阅读漫画和小说，或者把喜欢的作品加入下载队列。Pixiv Toolbox 提供浏览器扩展和 Tampermonkey 脚本两个版本，界面和主要功能共用一套实现。

目前这是一个开发版本：部分页面、真实账号操作和云服务还没有完成全面实测。如果遇到问题，可以先查看任务面板中的错误信息。

## 安装

选择下面一种方式即可。安装文件位于 `dist/`；如果还没有这个目录，请先参考文末的[构建方法](#从源码构建)。

### 浏览器扩展

适用于 Edge 和 Chrome（Chromium 120 或更新版本）。

1. 解压 `dist/pixiv-toolbox-0.1.0-mv3.zip`。
2. 打开浏览器的扩展管理页面，启用“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中刚才解压出来的目录。
4. 打开或刷新 Pixiv 页面。

也可以直接加载构建生成的 `dist/extension/` 目录。

### Tampermonkey 脚本

1. 安装并启用 Tampermonkey。
2. 在 Tampermonkey 中安装 `dist/userscript/pixiv-toolbox.user.js`。
3. 在 Pixiv 页面刷新后使用。新版 Chromium 可能需要先在 Tampermonkey 的扩展详情页开启“允许用户脚本”；下载时也可能需要在管理器中允许相应文件类型。

两个版本可以同时安装，但检测到扩展运行时，脚本会让出界面并暂停脚本任务。停用扩展并刷新页面后，可以从 Tampermonkey 菜单选择“恢复脚本任务”。两种版本的数据各自保存，不会自动互通。

## 开始使用

进入 Pixiv 后，页面右下角会出现“作品工作台”“任务”“历史”和“设置”。需要收藏、关注或下载受账号权限限制的作品时，请先登录 Pixiv。

### 预览和阅读

把鼠标移到缩略图的中央即可打开预览，不需要等待。默认触发区域的宽和高各占缩略图的 50%；如果觉得太容易或太难触发，可以在“设置 → 浏览与阅读”中调整。点击预览中的“固定”后，可以继续操作图片或阅读内容。

查看器支持多页翻页、滚轮缩放、拖动平移、旋转和全屏。动图可以暂停、逐帧查看和调整播放速度；小说可以调整字号、行距和阅读进度。预览中也可以直接收藏作品、关注作者，或从作者菜单下载头像和封面。

| 快捷键 | 操作 |
| --- | --- |
| `←` / `→` | 上一页 / 下一页 |
| `J` / `K` | 下一件 / 上一件作品 |
| `Space` | 播放或暂停动图 |
| `F` | 切换全屏 |
| `Esc` | 关闭查看器 |

### 工作台和下载

在作品列表页面打开“作品工作台”，可以一边浏览列表，一边查看作品。勾选作品后选择“下载选中”，任务会进入下载队列；“任务”面板中可以查看进度、暂停或重试。工作台底部可以手动加载下一页，也可以勾选自动加载。

单件作品可以下载原图、当前页或指定页。展开查看器顶部的“收藏标签与选页下载”，输入 `1,3-5` 这样的页码即可选择页面；在设置中还可以将多页作品打包为 ZIP。动图支持下载原始帧 ZIP 和时序 JSON，或导出 GIF、MP4、WebM；小说支持 TXT 和 EPUB。

“下载与文件”设置中可以选择保存目录、调整文件名模板和下载并发数，也可以为 JPEG、PNG 写入作品元数据。模板支持 `{artist}`、`{title}`、`{id}` 和 `{page}`；文件名中的页码从 0 开始，而指定下载页面时使用从 1 开始的页码。

如果任务显示“待确认”，请先检查文件是否已经保存，再选择确认。浏览器无法确认结果时，工具不会自动重复下载。自选目录的授权失效后，需要重新选择并授权。

### 筛选、历史和备份

可以按收藏数筛选或排列已载入的作品，也可以隐藏已收藏、已关注或已读内容，屏蔽指定作者和标签，并关闭成人或 AI 内容。筛选和排序依赖已经取得的作品详情，未载入的作品不参与当前排序。

“历史”中可以继续阅读之前打开的作品。“设置 → 数据、定时与云同步”可以导出备份。备份包含设置、阅读记录和下载记录，不包含云端凭据；导入时恢复设置和阅读记录，备份中的下载记录不会被当作本机已有文件的证明。

替换已有作品的收藏标签时，新标签会覆盖原有标签，公开或私密状态保持不变。

### 定时任务和云端

设置中可以填写 Pixiv 列表页面、抓取间隔和每次的作品数量，添加定时下载任务。浏览器完全退出时任务不会运行；脚本版还需要至少保留一个运行脚本的页面。

如需使用 WebDAV 或提供 WebDAV 接口的 Alist，在设置中填写 HTTPS 目录、用户名和密码，再选择是否上传下载的文件。扩展版需要在扩展设置页配置，保存时会请求对应主机的访问权限；脚本版按 Tampermonkey 的提示授权。凭据保存在本机，不会写入备份。设置和阅读记录可以双向同步；服务端需要支持 ETag 和条件写入，否则可以使用本地备份。

## 使用时遇到问题

- **没有看到工具栏**：确认扩展或脚本已启用，刷新 Pixiv 页面；如果同时安装了两种版本，检查是否由扩展接管了界面。
- **下载失败或暂停**：打开“任务”查看原因，检查登录状态、浏览器或脚本管理器的下载权限，以及保存目录授权。
- **动图无法导出**：MP4 和 WebM 需要浏览器支持相应编码器；文件过大或帧数过多时也会提示超出资源限制。
- **云同步失败**：检查 WebDAV 地址和授权。如果服务端不提供 ETag 或不支持条件写入，双向同步无法使用。

## 从源码构建

需要 Node.js 24、pnpm 和已安装并可在命令行运行的 BetterLeaks。在项目目录中执行：

```sh
pnpm install --frozen-lockfile
pnpm build
```

构建结果放在 `dist/`。每个构建阶段结束后会使用 BetterLeaks 扫描工作树；扫描失败时构建会停止。

开发时可用 `pnpm typecheck`、`pnpm test` 和 `pnpm test:browser` 检查。浏览器测试需要可用的测试浏览器；用户脚本界面测试使用 GM 接口夹具，不等同于真实 Tampermonkey 的安装验证。

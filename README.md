# Pixiv Toolbox

轻量的 Pixiv 浏览、阅读、整理与下载工具。同一份 TypeScript 和 Vue 界面构建 Chromium MV3 扩展与 Tampermonkey 用户脚本。

## 安装

- **扩展**：解压 `pixiv-toolbox-0.1.0-mv3.zip`，在 Edge／Chrome 扩展管理页加载解压后的目录。
- **用户脚本**：安装 Tampermonkey 后安装 `pixiv-toolbox.user.js`。新版 Chromium 需在管理器扩展详情中允许用户脚本。下载功能可能需要按 Tampermonkey 提示授予下载权限、允许对应文件类型。
- 两种版本选一个作为主要运行方式。同时检测到 MV3 时，脚本暂停新任务并让出界面；停用扩展后可从 Tampermonkey 菜单恢复脚本任务。

进入 Pixiv 后，右下角有工作台、任务、历史和设置入口。缩略图**中央宽高各 50%**区域即时触发预览，比例可调，无停留延迟。预览可固定，支持翻页、缩放、平移、旋转、全屏、动图播放控制与小说阅读。工作台支持列表分页、选择下载、筛选排序和作者／标签屏蔽。

## 功能

- 浏览：中央即时悬停、多图漫画、动图暂停／逐帧／变速、键盘导航、有限预载、双栏工作台及自动分页。
- 下载：原图、选页、整组 ZIP、跨作品队列、头像／封面、Ugoira 帧 ZIP 与时序、GIF／MP4／WebM、小说 TXT／EPUB。
- 整理：收藏数过滤排序、隐藏收藏／关注／已读、R18／AI 过滤、黑名单、关注高亮、快捷收藏关注与明确替换收藏标签。
- 数据：历史与阅读进度、命名模板、JPEG／PNG 元数据、备份恢复、定时任务、WebDAV 图片上传及设置／阅读记录同步。

查看器快捷键：左右键翻页，J／K 切作品，Space 播放动图，F 全屏，Esc 关闭。文字输入时不拦截快捷键。

## 行为边界

这是首个开发版本。Pixiv 接口和页面适配参考真实接口形状并经过夹具测试，尚未使用用户真实账号验证所有页面、收藏写入和云服务。

- 脚本任务依赖打开的执行页；所有执行页关闭后等待恢复。浏览器完全退出时两端都不运行定时任务。
- 下载只有在浏览器／管理器确认成功后才计入完成。保存结果无法核实时保留“待确认”，不会自动重复下载。
- 自选目录授权失效会暂停；不会悄悄更换保存位置。脚本目录授权只在当前页面保留。
- 收藏标签输入表示**替换为新列表**，不把作者的作品标签冒充原有收藏标签；替换已有收藏标签时保留真实的公开／私密状态。
- 排序基于已取得的作品详情；发现列表没有稳定页码，按批次去重并有数量边界。
- 历史备份不包含登录信息和云端凭据，导入的下载历史不作为本机已经拥有文件的证明。
- 云端地址由用户配置。扩展只在用户操作时申请该主机，脚本使用管理器授权；请求层再次限制到已配置的云端目录。配置凭据只保存到本机私有存储。
- 双向同步要求服务提供 ETag 和条件写入；不同内容的同名图片不会被自动覆盖，响应丢失后可按大小与摘要核实同一文件。
- 动图和归档有明确资源上限，超出时报错，不静默降画质。预览解码预算约 128 MiB，单资源 128 MiB，导出 256 MiB，单帧约 16M 像素，动图最多 2000 帧／10 分钟。
- 浏览器编码能力决定 MP4／WebM 是否可用。GIF 有格式自身的色彩和时间精度限制。

## 开发与验证

使用 Node.js 24 与 pnpm。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm test:browser
```

构建输出到 `dist/`，每个构建阶段成功后都会运行 BetterLeaks，扫描当前 Git 工作树中的可提交源码、脚本、配置及未跟踪文件，使用 `--redact`。Windows 使用已验证的 stdlib 引擎，避免 RE2 缓存跨盘错误。扫描失败会停止打包。

浏览器测试分清两类证据：媒体使用真实 Edge 编码器和视频／图片解码；用户脚本 UI 测试加载发布产物但通过 GM 桥接提供夹具数据，不等同于真实 Tampermonkey 的安装和权限验证。MV3 安装包测试使用隔离 Chromium 配置；如需指定官方测试浏览器，可通过 `PIXIV_TEST_BROWSER` 提供可执行文件位置。

开发数据和测试浏览器保存在忽略的 `.local/`、`test-results/`。凭据、个人地址、个人路径和浏览器配置不进入 Git。
